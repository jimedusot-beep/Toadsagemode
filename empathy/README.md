# Empathy Learning Library
These are short original examples inspired by supportive communication principles, **not** transcripts of Mister Rogers or Ms. Rachel. Do not upload copyrighted transcripts or personal chats without permission. The goal is to evaluate communication behaviors, not teach a model to claim that it experiences feelings.

Each record has an emotion, context, example response, principle, and failure mode. Future evaluations should check for emotional validation, age-appropriate phrasing, respect for choice and boundaries, support for real human relationships, and refusal to invent emotional certainty. This collection is NOT fine-tuning data by itself. Review for cultural and accessibility differences. Do not treat this as crisis support or diagnosis.

Deployment checklist
1. Obtain an authorized Linux host. 2. Install Docker and Ollama on the host. 3. Transfer the Sage Toad agent package. 4. Run its installer. 5. Import the curriculum JSON downloaded here. 6. Launch the agent under tmux.
No live-status feature is enabled. A protected backend would be necessary to display actual agent progress.
